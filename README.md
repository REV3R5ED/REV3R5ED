## 💼 What I Do

I design **transparent, guard-railed, open-source defensive tooling** for SOC analysts and DFIR practitioners built for real-world investigations, not just demos. From phishing forensics to packet-level incident response, I turn complex security workflows into **auditable, explainable, deterministic systems**.

- 🔍 **Email Forensics** → PhishScope turns phishing into reproducible evidence.
- 🖼️ **Metadata Forensics** → MetaTrace reconstructs the story behind images.
- 🖥️ **Host Forensics** → HuntForge interrogates Windows endpoints like a DFIR analyst.
- 📜 **Log Analysis** → LogLens gives you structured, explainable triage.
- 🌐 **Network Diagnostics** → NetScope finds what's actually wrong with the network.
- 🛡️ **Threat Hunting** → SentinelKit is my unified CLI for SOC triage.
- ⚙️ **DFIR Platform Engineering** → AegisForge ties this workflow together.
- 🤖 **IT Automation** → AutoOPS makes safe, dry-run-first IT automation real.
- 📊 **Interactive Workbench** → AegisBoard brings all 8 engines to the browser.
- 🧪 **DFIR Investigation Lab** → BlackEcho is my end-to-end training lab: one breach, one full investigation, zero uncertainty.
